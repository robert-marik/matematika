# Přehled symbolů

> * Přehled nejčastěji používaných symbolů v přednáškách a cvičeních.
> * Značení se liší mezi obory (matematika, fyzika, nauka o dřevě, hydrologie) i mezi zdroji, ze kterých text čerpá. Proto se pro stejnou veličinu někdy používá více symbolů a naopak jeden symbol může mít v různých kapitolách různý význam. Takové případy jsou v tabulkách výslovně uvedeny.
> * Rozhodující je vždy význam symbolu uvedený v textu u daného vzorce.

## Funkce, derivace a integrály

| Symbol | Význam | Poznámka |
|---|---|---|
| $\mathrm{D}(f)$, $\mathrm{Dom}(f)$ | definiční obor funkce $f$ | |
| $\mathrm{H}(f)$ | obor hodnot funkce $f$ | |
| $f'(x)$, $\frac{\mathrm df}{\mathrm dx}$ | derivace funkce $f$ (rychlost změny) | |
| $f''(x)$, $f^{(n)}(x)$ | druhá a $n$-tá derivace | |
| $\frac{\partial f}{\partial x}$ | parciální derivace podle $x$ | |
| $\Delta x$, $\Delta f$ | (konečná) změna veličiny | |
| $O\bigl((x-x_0)^{n+1}\bigr)$ | Landauovo velké O, zbytek Taylorova polynomu | |
| $\int f(x)\,\mathrm dx$ | neurčitý integrál (primitivní funkce) | |
| $\int_a^b f(x)\,\mathrm dx$ | určitý integrál | |
| $\iint_M f(x,y)\,\mathrm dx\,\mathrm dy$ | dvojný integrál přes množinu $M$ | |
| $C$, $c$ | integrační konstanta | |
| $\mathbb R$, $\mathbb R^2$ | množina reálných čísel, rovina | |

| $A^{-1}$ | inverzní matice | |
| $I$ | jednotková matice | |
| $\det A$ | determinant matice $A$ | |
| $\lambda$ | vlastní číslo | ve fyzikálních kapitolách též tepelná vodivost |
| $AX=B$, $A\vec x=\vec b$ | maticový zápis soustavy lineárních rovnic | $A$ matice soustavy, $B$ resp. $\vec b$ vektor pravých stran |
